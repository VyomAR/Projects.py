# 100 Days of Python Projects

My solutions to the **100 Days of Code: Python** course on Udemy. I'm building one project a day and pushing it here to track my progress.

## Progress

| Day | Project | Concepts Used |
|-----|---------|---------------|
| 04  | [Rock Paper Scissors](day_04_Rock_Paper_Scissors) | Lists, randomisation, conditionals |

## Project Structure

Each day has its own folder:

```
Projects.py/
├── day_04_Rock_Paper_Scissors/
│   └── main.py
├── day_05_.../
└── README.md
```

## How to Run

1. Clone the repo:
   ```
   git clone https://github.com/VyomAR/Projects.py.git
   ```
2. Open a day's folder:
   ```
   cd Projects.py/day_04_Rock_Paper_Scissors
   ```
3. Run it:
   ```
   python main.py
   ```

Requires Python 3.x.
